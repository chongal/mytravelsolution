# mytravel.kz Hackathon - Сбор, анализ и оценка туристических объектов

## 1. Описание проекта

Мы создали систему ИИ-агентов, которая **автоматически собирает, анализирует и оценивает туристические объекты размещения в Казахстане** (глэмпинги, гостевые дома, юрты, эко-коттеджи) и позволяет проводить **outreach к другим компаниям**.  
Вся работа велась в **Google Colab**, используя Python, внешние API и ИИ-модели.

---

## 2. Что мы сделали

### Сбор данных

1. **2GIS:**  
   - Собрали объекты через `2GIS organization collection` и `2GIS data collection`.  
   - Объединили данные по URL, чтобы каждый объект имел полный профиль.  
   - Пробежались циклом `for` для Packet merging.

2. **Instagram:**  
   - Настроили Packets и `Account info retriever` для получения информации об аккаунтах.  
   - Парсили **посты за последний месяц**: количество лайков, комментариев, активность.  
   - Использовали циклы `for`, чтобы вставить Instagram-профили из 2GIS в Packet merging.

---

### Обработка и объединение данных

1. **ИИ-анализ с Ollama:**  
   - Установили Ollama в Colab.  
   - Работали с `Model interaction` для анализа текстов объектов.  
   - Использовали `Website summarizer` для кратких описаний страниц объектов.  
   - Создали `Description merger` и добавили результаты в CSV.

2. **Outreach к компаниям (Email sender):**  
   - Автоматически генерируем персонализированные письма для **других компаний**.  
   - Письма строятся на основе собранной информации: рейтинг, лайки, комментарии, описание.  
   - CSV-файл выступает источником данных для массового outreach.

---

### Оценка объектов (Assessment and Outreach)

- Из CSV брали метрики: лайки, комментарии, рейтинг 2GIS, дополнительные фичи.  
- Разработали формулу оценки и присвоили каждому объекту категорию **Hot / Warm / Cold**.  
- Метрики:

| Критерий                 | Значение                                                                 |
|---------------------------|--------------------------------------------------------------------------|
| Активность в сети         | Частота постов, подписчики, ответы на комментарии                        |
| Полнота данных            | Контакты, фото, описание                                                 |
| Популярность              | Упоминания, отзывы, рейтинги                                             |
| Потенциал заполняемости   | Количество мест, цена, локация                                           |
| Соответствие ЦА           | Премиум сегмент, эко-туризм, семьи, молодежь                             |
| Коммерческий потенциал    | Способность платить за продвижение, профессионализм                      |

---

## 3. Результат

- CSV-файл с полной информацией о туристических объектах.  
- Система оценки объектов по ключевым метрикам.  
- Автоматизированный сбор данных с 2GIS и Instagram.  
- **Генерация персонализированных писем для outreach к другим компаниям.**  
- Полностью готовый пайплайн: сбор → анализ → объединение → оценка → коммуникация.
